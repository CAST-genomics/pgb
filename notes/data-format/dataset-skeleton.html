Anatomy of a Dataset

an illustrated skeleton of the pangenome graph format

A dataset is one JSON file describing a pangenome graph for a single locus — the alternative paths through a stretch of the genome, which assemblies walk which path, and where each piece sits in layout space. The file is large but shallow: only a handful of distinct shapes, repeated thousands of times. Each shape is drawn once below, with real values, as a nested rectangular region: every box is one object or one array, and every box that sits inside another is, literally, a child of it.

Specimen — public/datasets/api-v3/il7.json  ·  the IL7 locus on chromosome 8  ·  12 nodes  ·  466 assemblies
