Anatomy of a Dataset

an illustrated skeleton of the pangenome graph format

A dataset is one JSON file describing a pangenome graph for a single locus — the alternative paths through a stretch of the genome, which assemblies walk which path, and where each piece sits in layout space. The file is large but shallow: only a handful of distinct shapes, repeated thousands of times. Below, each repeated shape is drawn once, with real values, and annotated in the margin.
