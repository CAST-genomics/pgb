PanGenome Node Visual States

Three-state encoding for attribute presence in the assembly graph viewer.
Color temperature carries categorical meaning; saturation carries intensity.

#C0311A
State 01
Emphasis
Node carries the selected attribute name. This is the primary signal — the figure against ground. Heavy stroke, fully saturated warm red.
has attribute · selected name
#B07068
State 02
De-emphasis
Node has the attribute category, but not the selected name. A blood relative of emphasis — same chromatic family, drained of saturation. Light stroke weight reinforces its recessive role.
has attribute · different name
#7A92A3
State 03
Absent
Node lacks the attribute category entirely — it is outside the data space of this visualization. Cool blue-gray is categorically foreign to the warm red family, signaling a difference of kind, not degree.
no attribute · category missing
Warm axis (red → dusty rose) encodes within-category variation. Cool axis (blue-gray) encodes categorical absence. A viewer reads the temperature shift as a change in kind, not intensity.
